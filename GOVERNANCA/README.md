# GOVERNANCA — METATRADER5

## Regra de persistência
Todo artefato produzido para este projeto deve ser salvo no repositório, respeitando a estrutura oficial.

## Regras de engenharia
- Consultar o estado atual do GitHub antes de alterar arquivos.
- Preservar versões anteriores e evitar sobrescritas destrutivas.
- Usar commits pequenos, com mensagens objetivas.
- Documentar decisões arquiteturais e mudanças de contratos.
- Manter separação entre pesquisa, análise, risco e execução.
- Não permitir envio de ordens por módulos analíticos.
- O Risk Engine possui veto absoluto.
- Não declarar compilação, teste ou homologação sem evidência verificável.

## Estrutura
A estrutura definida no README é normativa. Novas pastas somente devem ser adicionadas quando houver justificativa técnica e documentação.
